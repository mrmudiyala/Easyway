# 🚀 EasyWay — Unified Mobility & Food Delivery Super-App

A full-stack, production-grade **Uber + Zomato style Super-App** combining **EasyWay Rides** and **EasyWay Food** built with **Node.js/Express, TypeScript, Socket.io, PostGIS / In-Memory Spatial Engine, and Interactive Leaflet Maps**.

---

## 🎯 2. How to Use the Super-App

1. Open your browser and navigate to:
   👉 **[http://localhost:4000](http://localhost:4000)**

2. In the top navigation bar, use the **Super-Switcher** to toggle between:
   * **🚖 EasyWay Rides**: Access the Rider Portal, AI Voice Orb, Symmetrical Fare Swap, Captain Portal, and Fleet Admin.
   * **🍔 EasyWay Food**: Access the Food App, Restaurant Menus, Cart Drawer, Kitchen Manager, Delivery Partner Portal, and Food Admin.

3. Click **"⚡ Run 30s Live Demo"** in either mode to watch an automated end-to-end presentation!
